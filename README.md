# 🛍️ Customer Behavior Analysis

An end-to-end data analytics project that takes a raw retail customer dataset from **cleaning → SQL analysis → interactive dashboard**, using **Python, SQL Server, and Power BI**.

---

## 📌 Project Overview

This project analyzes customer shopping behavior across demographics, product categories, shipping preferences, discounts, and subscriptions to uncover actionable business insights.

**Dataset:** 3,900 customer records × 18 features, including Age, Gender, Item Purchased, Category, Purchase Amount, Location, Size, Color, Season, Review Rating, Subscription Status, Shipping Type, Discount Applied, Promo Code Used, Previous Purchases, Payment Method, and Frequency of Purchases.

**Pipeline:**

```
Raw Data (CSV)
   → Python: Cleaning & EDA
      → SQL Server: Business Analysis
         → Power BI: Interactive Dashboard
```

## 🐍 1. Data Cleaning & EDA (Python)

Performed in `Customer_behaviour.ipynb`:

- Initial inspection with `.info()`, `.describe()`, and `.shape`
- Null value and duplicate detection, followed by cleanup (`dropna()`, `duplicated()`)
- Unique-value exploration across all categorical columns (Gender, Item Purchased, Category, Location, Season, Payment Method, Frequency of Purchases, etc.)
- Outlier detection and removal on numeric columns using the **IQR method**
- Re-merged cleaned categorical and numeric subsets into a single dataframe
- Column renaming for consistency (e.g. `Purchase Amount (USD)` → `Purchase_Amount_USD`)
- Exported the cleaned dataset to `new_customer_beahvior.csv`
- Loaded the cleaned CSV directly into SQL Server using `SQLAlchemy` + `pyodbc`

---

## 🗄️ 2. Business Analysis (SQL Server)

Wrote and executed 10 business-driven queries against the `Customer_Behavior` table:

1. Total revenue generated by male vs. female customers
2. Customers who used a discount but still spent above the average purchase amount
3. Top 5 products by average review rating
4. Average purchase amount: Standard vs. Express shipping
5. Revenue and average spend: subscribers vs. non-subscribers
6. Top 5 products with the highest percentage of discounted purchases
7. Customer segmentation into **New / Returning / Loyal** based on total previous purchases
8. Top 3 best-selling products within each category
9. Subscription rate among repeat buyers (5+ previous purchases)
10. Revenue contribution by age group (Youth / Semi-Adult / Adult)

All queries are available in [`https://drive.google.com/file/d/1wKCEe8_re23KMpjw-Pt4A6FrSrqs0rCe/view?usp=drive_link).

## 🚀 How to Reproduce

1. **Clone the repo**
   ```bash
   git clone https://github.com/<your-username>/customer-behavior-analysis.git
   cd customer-behavior-analysis
   ```
2. **Run the Python cleaning pipeline**
   ```bash
   pip install pandas sqlalchemy pyodbc
   jupyter notebook notebooks/Customer_behaviour.ipynb
   ```
3. **Load into SQL Server**
   - The notebook's final cells create a connection via `SQLAlchemy`/`pyodbc` and push the cleaned CSV into a `Customer_Behavior` table.
   - Update `server_name` and `database_name` in the notebook to match your local SQL Server instance.
4. **Run the SQL queries**
   - Open `queries/customer_behavior_analysis.sql` in SQL Server Management Studio (or Azure Data Studio) against the `Customer_Behavior` table.
5. **Open the dashboard**
   - Open `dashboard/Customer_behavior_project.pbix` in Power BI Desktop and refresh the data source to point to your SQL Server instance.
